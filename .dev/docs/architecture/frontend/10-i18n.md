# Internationalization (i18n)

> **Reference implementation:** [`app/root.tsx`](../../../../app/root.tsx), [`src/app/i18n/`](../../../../src/app/i18n/)

## Обзор

| Аспект | Решение |
|--------|---------|
| Библиотека | i18next + react-i18next |
| Lazy loading | i18next-http-backend |
| Формат | JSON (`public/locales/{lng}/translation.json`) |
| Языки | `en`, `ru` |
| SSR | Переводы загружаются на сервере, передаются клиенту |

## Файлы


## Поток данных

```
REQUEST
    ↓
SERVER: loader() → getI18nData(request)
    ↓  - Читает cookie i18nextLng
    ↓  - Fallback на Accept-Language header
    ↓  - Загружает JSON с диска
    ↓
SERVER: Render → <html lang="ru">
    ↓
CLIENT: initI18n({ locale, translations })
    ↓  - Синхронная инициализация (переводы уже есть)
    ↓  - Нет loading state
    ↓
CLIENT: Смена языка → i18n.changeLanguage('en')
    ↓  - Lazy load /locales/en/translation.json
    ↓  - Сохранение в localStorage + cookie
```

## Приоритет определения языка

| Контекст | Приоритет | Причина |
|----------|-----------|---------|
| **SSR** | Cookie → Accept-Language → default | localStorage недоступен |
| **Client** | localStorage → Cookie → default | localStorage актуальнее |

## Смена языка

```tsx
// src/app/i18n/i18n.ts
export const changeLanguage = async (lng: string) => {
  await i18n.changeLanguage(lng)           // Lazy load если нужно
  localStorage.setItem('i18nextLng', lng)  // Для клиента
  document.cookie = `i18nextLng=${lng}...` // Для SSR
}
```

**Без перезагрузки страницы** — i18next подгружает переводы через http-backend.

## Использование

### Базовое

```tsx
import { useTranslation } from 'react-i18next'

export const SignInForm = () => {
  const { t } = useTranslation()

  return (
    <form>
      <h1>{t('auth.signIn.title')}</h1>
      <Input placeholder={t('auth.signIn.emailPlaceholder')} />
      <Button>{t('auth.signIn.submitButton')}</Button>
    </form>
  )
}
```

### С интерполяцией

```json
// public/locales/en/translation.json
{
  "validation": {
    "passwordMin": "Password must be at least {{min}} characters"
  }
}
```

```tsx
t('validation.passwordMin', { min: 8 })  // "Password must be at least 8 characters"
```

### Pluralization

```json
// public/locales/en/translation.json
{
  "dashboard": {
    "mapCard": {
      "concepts": "{{count}} item",
      "concepts_other": "{{count}} items"
    }
  }
}

// public/locales/ru/translation.json
{
  "dashboard": {
    "mapCard": {
      "concepts_one": "{{count}} элемент",
      "concepts_few": "{{count}} элемента",
      "concepts_many": "{{count}} элементов"
    }
  }
}
```

```tsx
t('dashboard.mapCard.concepts', { count: 5 })  // "5 items" / "5 элементов"
```

## Структура переводов

```json
// public/locales/en/translation.json
{
  "auth": {
    "signIn": { "title": "...", "submitButton": "..." },
    "signUp": { "..." }
  },
  "common": {
    "save": "Save",
    "cancel": "Cancel",
    "loading": "Loading"
  },
  "validation": {
    "email": "Invalid email",
    "required": "Required field"
  },
  "nav": { "..." },
  "dashboard": { "..." },
  "graph": { "..." },
  "editor": { "..." },
  "settings": { "..." },
  "errors": { "..." }
}
```

**Принципы:**
- Группировка по доменам (auth, dashboard, settings)
- Вложенность для связанных строк (signIn.title, signIn.submitButton)
- Общие строки в `common`
- Ошибки валидации в `validation`

## Форматирование

### Даты (Intl API)

```tsx
// shared/lib/format-date.ts
export const formatDate = (date: Date, locale: string) => {
  return new Intl.DateTimeFormat(locale, {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  }).format(date)
}

// Использование
const { i18n } = useTranslation()
formatDate(new Date(), i18n.language)  // "December 5, 2025" / "5 декабря 2025"
```

### Числа и валюта

```tsx
export const formatCurrency = (amount: number, locale: string, currency = 'USD') => {
  return new Intl.NumberFormat(locale, {
    style: 'currency',
    currency
  }).format(amount)
}
```
