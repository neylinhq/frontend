# Internationalization (i18n)

> **Фреймворк**: React Router 7 (SSR)

## Обзор

| Аспект | Решение |
|--------|---------|
| Библиотека | i18next + react-i18next |
| Backend | i18next-http-backend (lazy loading) |
| Detection | SSR: Cookie → Accept-Language; Client: localStorage → Cookie |
| Формат | JSON (`public/locales/{lng}/translation.json`) |
| Fallback | English |
| SSR | Синхронная инициализация с серверными переводами |

## Эталонная реализация (Neylin)

### Слой 1: Server — Чтение переводов

```tsx
// app/i18n/i18n.server.ts
import * as fs from 'node:fs'
import * as path from 'node:path'

export const supportedLanguages = ['en', 'ru'] as const
export type SupportedLanguage = (typeof supportedLanguages)[number]
export const defaultLanguage: SupportedLanguage = 'en'

/**
 * Читает переводы с диска (синхронно, для SSR)
 */
export const getTranslations = (locale: SupportedLanguage): Record<string, unknown> => {
  const filePath = path.join(process.cwd(), 'public', 'locales', locale, 'translation.json')

  try {
    const content = fs.readFileSync(filePath, 'utf-8')
    return JSON.parse(content)
  } catch {
    // Fallback to default language
    if (locale !== defaultLanguage) {
      return getTranslations(defaultLanguage)
    }
    return {}
  }
}

/**
 * Определяет язык из Accept-Language header
 */
export const detectLanguage = (acceptLanguage: string | null): SupportedLanguage => {
  if (!acceptLanguage) return defaultLanguage

  // Parse "ru-RU,ru;q=0.9,en-US;q=0.8,en;q=0.7"
  const languages = acceptLanguage
    .split(',')
    .map(lang => {
      const [code, q = 'q=1'] = lang.trim().split(';')
      return {
        code: code.split('-')[0].toLowerCase(),
        quality: parseFloat(q.replace('q=', '')) || 1
      }
    })
    .sort((a, b) => b.quality - a.quality)

  for (const { code } of languages) {
    if (supportedLanguages.includes(code as SupportedLanguage)) {
      return code as SupportedLanguage
    }
  }

  return defaultLanguage
}

/**
 * Получает i18n данные для SSR — вызывается в root loader
 */
export const getI18nData = (request: Request) => {
  const cookieHeader = request.headers.get('Cookie')

  // Приоритет: cookie > Accept-Language > default
  const cookieLocale = cookieHeader
    ?.split(';')
    .find(c => c.trim().startsWith('i18nextLng='))
    ?.split('=')[1]
    ?.trim()

  const locale = (
    supportedLanguages.includes(cookieLocale as SupportedLanguage)
      ? cookieLocale
      : detectLanguage(request.headers.get('Accept-Language'))
  ) as SupportedLanguage

  const translations = getTranslations(locale)

  return { locale, translations }
}
```

### Слой 2: Client — Инициализация

```tsx
// app/i18n/i18n.ts
import i18n from 'i18next'
import LanguageDetector from 'i18next-browser-languagedetector'
import Backend from 'i18next-http-backend'
import { initReactI18next } from 'react-i18next'

export interface I18nInitData {
  locale: string
  translations: Record<string, unknown>
}

let initialized = false

/**
 * Инициализация i18n с SSR данными
 */
export const initI18n = (data?: I18nInitData) => {
  if (initialized) return i18n

  if (data?.translations) {
    // SSR mode: синхронная инициализация с готовыми переводами
    i18n
      .use(Backend)
      .use(initReactI18next)
      .init({
        lng: data.locale,
        fallbackLng: 'en',
        debug: false,
        initImmediate: true,  // Синхронно!

        // Текущий язык уже загружен
        resources: {
          [data.locale]: {
            translation: data.translations
          }
        },
        partialBundledLanguages: true,  // Остальные загрузим через Backend

        backend: {
          loadPath: '/locales/{{lng}}/{{ns}}.json'
        },

        react: {
          useSuspense: false  // Нет flash при SSR
        },

        interpolation: {
          escapeValue: false  // React экранирует
        }
      })
  } else {
    // Client-only fallback
    i18n
      .use(Backend)
      .use(LanguageDetector)
      .use(initReactI18next)
      .init({
        fallbackLng: 'en',
        debug: import.meta.env.DEV,
        detection: {
          order: ['localStorage', 'navigator'],
          lookupLocalStorage: 'i18nextLng',
          caches: ['localStorage']
        },
        react: { useSuspense: true },
        interpolation: { escapeValue: false },
        backend: { loadPath: '/locales/{{lng}}/{{ns}}.json' }
      })
  }

  initialized = true
  return i18n
}

export default i18n
```

### Слой 3: Root Loader + App

```tsx
// app/root.tsx
export const loader = async ({ request }: Route.LoaderArgs) => {
  const { getI18nData } = await import('@/app/i18n/i18n.server')
  const i18nData = getI18nData(request)
  return { i18n: i18nData }
}

const App = () => {
  const { i18n: i18nData } = useLoaderData<typeof loader>()
  const initializedRef = useRef(false)

  // Инициализация i18n с SSR данными (один раз)
  if (!initializedRef.current) {
    initI18n(i18nData as I18nInitData)
    initializedRef.current = true
  }

  // Sync locale to html lang
  useEffect(() => {
    document.documentElement.lang = i18nData.locale
  }, [i18nData.locale])

  return (/* ... */)
}
```

### Слой 4: Blocking Script (синхронизация)

```tsx
// app/root.tsx — в <head>
<script dangerouslySetInnerHTML={{
  __html: `
    (function() {
      try {
        // Locale (localStorage > cookie)
        var localLocale = localStorage.getItem('i18nextLng');
        var cookieLocale = document.cookie.match('(^|;)\\\\s*i18nextLng\\\\s*=\\\\s*([^;]+)')?.pop();
        var locale = localLocale || cookieLocale || 'en';

        document.documentElement.lang = locale;

        // Sync localStorage -> cookie
        if (localLocale && localLocale !== cookieLocale) {
          document.cookie = 'i18nextLng=' + localLocale + '; path=/; max-age=31536000; SameSite=Lax';
        }
      } catch (e) {}
    })();
  `
}} />
```

### Слой 5: Language Switcher

```tsx
// shared/components/language-switcher/language-switcher.tsx
import { useTranslation } from 'react-i18next'

const LANGUAGES = [
  { id: 'en', label: 'English' },
  { id: 'ru', label: 'Русский' }
]

export const LanguageSwitcher = () => {
  const { i18n } = useTranslation()

  const changeLanguage = (lng: string) => {
    // 1. Меняем язык в i18next (триггерит lazy load если нужно)
    i18n.changeLanguage(lng)

    // 2. Сохраняем в localStorage (для useEffect синхронизации)
    localStorage.setItem('i18nextLng', lng)

    // 3. Сохраняем в cookie (для следующего SSR)
    document.cookie = `i18nextLng=${lng}; path=/; max-age=31536000; SameSite=Lax`
  }

  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button variant='ghost' size='icon'>
          <Globe className='h-4 w-4' />
        </Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        {LANGUAGES.map(lang => (
          <DropdownMenuItem key={lang.id} onClick={() => changeLanguage(lang.id)}>
            {lang.label}
          </DropdownMenuItem>
        ))}
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

## Приоритет определения locale

**Важно:** Приоритеты различаются между SSR и Client из-за доступности API:

| Контекст | Приоритет | Причина |
|----------|-----------|---------|
| **SSR** | Cookie → Accept-Language → default | `localStorage` недоступен на сервере |
| **Client** | localStorage → Cookie → default | `localStorage` — актуальный выбор пользователя |

**Почему это не противоречие:**

1. **SSR не имеет доступа к localStorage** — может читать только headers (Cookie, Accept-Language)
2. **localStorage содержит актуальный выбор** — пользователь мог сменить язык после загрузки страницы
3. **Blocking script синхронизирует** — если localStorage ≠ cookie, скрипт обновляет cookie для следующего SSR

```
Первый визит:
  SSR: Accept-Language: ru → locale=ru
  Client: localStorage пуст → берём из SSR

Пользователь меняет на en:
  Client: localStorage=en, cookie=en (синхронизация)

Следующий визит:
  SSR: Cookie=en → locale=en (совпадает с localStorage)
```

## Архитектура решения

```
┌─────────────────────────────────────────────────────────────────┐
│ REQUEST                                                          │
└─────────────────────────┬───────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│ 1. SERVER: getI18nData(request)                                  │
│    └─ Cookie i18nextLng → Accept-Language → default              │
│    └─ fs.readFileSync('public/locales/ru/translation.json')      │
│    └─ Return { locale: 'ru', translations: {...} }               │
└─────────────────────────┬───────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│ 2. SERVER: Render HTML                                           │
│    └─ Blocking script: sync localStorage → cookie                │
│    └─ <html lang="ru">                                           │
└─────────────────────────┬───────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│ 3. CLIENT: Hydration                                             │
│    └─ initI18n({ locale, translations })                         │
│    └─ Синхронная инициализация (initImmediate: true)             │
│    └─ Переводы уже есть — нет loading state                      │
└─────────────────────────┬───────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│ 4. CLIENT: Language Switch                                       │
│    └─ i18n.changeLanguage('en')                                  │
│    └─ i18next-http-backend загружает /locales/en/translation.json│
│    └─ Cookie + localStorage обновляются                          │
└─────────────────────────────────────────────────────────────────┘
```

## Использование

### Базовое

```tsx
import { useTranslation } from 'react-i18next'

export const SignInForm = () => {
  const { t } = useTranslation()

  return (
    <form>
      <h1>{t('auth.signIn.title')}</h1>
      <Input placeholder={t('auth.signIn.emailPlaceholder')} />
      <Button>{t('auth.signIn.submitButton')}</Button>
    </form>
  )
}
```

### С интерполяцией

```json
// public/locales/en/translation.json
{
  "validation": {
    "passwordMin": "Password must be at least {{min}} characters"
  }
}
```

```tsx
t('validation.passwordMin', { min: 8 })  // "Password must be at least 8 characters"
```

## Форматирование

### Даты (Intl API)

```tsx
// shared/lib/format-date.ts
export const formatDate = (date: Date, locale: string) => {
  return new Intl.DateTimeFormat(locale, {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  }).format(date)
}

// Использование
const { i18n } = useTranslation()
formatDate(new Date(), i18n.language)  // "December 5, 2025" / "5 декабря 2025"
```

### Числа и валюта

```tsx
export const formatCurrency = (amount: number, locale: string, currency = 'USD') => {
  return new Intl.NumberFormat(locale, {
    style: 'currency',
    currency
  }).format(amount)
}
```

## Known Limitations

| Проблема | Причина | Решение |
|----------|---------|---------|
| localStorage ≠ SSR locale | Пользователь сменил язык на другом устройстве | Blocking script синхронизирует |
| `fs.readFileSync` каждый запрос | Нет кэширования | Добавить in-memory cache в production |
| Текст mismatch при locale mismatch | localStorage locale ≠ cookie | Перезагрузка или soft navigation |

### Потенциальное улучшение: Кэширование

```tsx
// app/i18n/i18n.server.ts
const translationsCache = new Map<string, Record<string, unknown>>()

export const getTranslations = (locale: SupportedLanguage) => {
  if (translationsCache.has(locale)) {
    return translationsCache.get(locale)!
  }

  const content = fs.readFileSync(filePath, 'utf-8')
  const translations = JSON.parse(content)

  if (process.env.NODE_ENV === 'production') {
    translationsCache.set(locale, translations)
  }

  return translations
}
```
