## Rust модули

### `lib.rs` — Entry Point

```rust
// src/lib.rs
mod graph;
mod layout;
mod spatial;
mod bindings;

pub use bindings::GraphEngine;
```

Единственный публичный export — `GraphEngine` для WASM.

### `graph/` — Data Structures

| Файл | Содержимое |
|------|------------|
| `mod.rs` | Re-exports |
| `node.rs` | `Node` struct, `NodeType` enum |
| `edge.rs` | `Edge` struct, `RelationType` enum |
| `graph.rs` | `Graph` container, adjacency lists |

### `layout/` — Algorithms

| Файл | Содержимое |
|------|------------|
| `mod.rs` | Re-exports, `LayoutResult` |
| `force_directed.rs` | Main layout algorithm |
| `quadtree.rs` | Barnes-Hut spatial tree |
| `config.rs` | `LayoutOptions`, constants |

### `spatial/` — Indexing

| Файл | Содержимое |
|------|------------|
| `mod.rs` | Re-exports |
| `viewport.rs` | Camera state, visible bounds |
| `hit_test.rs` | Point-in-node detection |

### `bindings/` — JS Interop

| Файл | Содержимое |
|------|------------|
| `mod.rs` | `GraphEngine` wasm_bindgen struct |
| `js_types.rs` | Serde types for JSON exchange |

## Naming Conventions

### Rust

| Элемент | Convention | Пример |
|---------|------------|--------|
| Modules | snake_case | `force_directed.rs` |
| Structs | PascalCase | `GraphEngine` |
| Functions | snake_case | `run_layout()` |
| Constants | SCREAMING_SNAKE | `DEFAULT_ITERATIONS` |
| Enums | PascalCase | `NodeType::Concept` |

### TypeScript

| Элемент | Convention | Пример |
|---------|------------|--------|
| Files | kebab-case | `use-graph-engine.hooks.ts` |
| Types | PascalCase | `WasmNode` |
| Functions | camelCase | `runLayout()` |
| Constants | SCREAMING_SNAKE | `DEFAULT_SPACING` |
