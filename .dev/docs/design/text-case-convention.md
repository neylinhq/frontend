# Text Case Convention

Правило регистра текста в интерфейсе Neylin.

---

## Принцип

**Sentence case everywhere. Zero exceptions.**

Первое слово с заглавной буквы, остальные — строчные (кроме имён собственных). Без uppercase, без Title Case, без lowercase-стиля.

Это вытекает из манифеста: "Строгий инструмент с тёплым сердцем". Sentence case читается как обычный текст — не командует, не кричит, не отстраняется.

---

## Почему не другие стили

| Стиль | Проблема для Neylin |
|-------|---------------------|
| **UPPERCASE** | Корпоративный, холодный. Создаёт ощущение "здесь всё серьёзно". Снижает скорость чтения на 13-20%. |
| **Title Case** | Формальный, Windows-стиль. "Reset Your Password" звучит как команда. Сложно для i18n — правила разные в каждом языке. |
| **lowercase** | Слишком casual, brutalist. Снижает читаемость. Не "строгий инструмент". |
| **Sentence case** | Читается как обычная речь. Тёплый, но не несерьёзный. Работает одинаково на всех языках. |

---

## Применение

### Все элементы интерфейса — sentence case

- **Заголовки страниц**: "Sign in to an account", "Вход в аккаунт"
- **Кнопки**: "Send code", "Sign in", "Отправить код", "Войти"
- **Табы**: "Node", "Chat", "Settings", "Узел", "Чат", "Настройки"
- **Form labels**: "Display name", "New password", "Имя профиля", "Новый пароль"
- **Section headers**: "Progress", "Mastery", "Прогресс", "Мастерство"
- **Badges**: "Public", "Concept", "Публичная", "Концепция"
- **Описания**: "Enter your email below", "Введите ваш email"
- **Ошибки и тосты**: "Sign in failed", "Не удалось войти"
- **Temporal groups**: "Today", "Yesterday", "Сегодня", "Вчера"
- **Placeholders**: "name@example.com", "Enter text..."

### Что делать с overline-лейблами

Вместо `uppercase tracking-wide` для визуального отделения используй:

```
text-xs font-medium text-muted-foreground
```

Иерархию создают размер, вес и цвет — не регистр.

### Имена собственные

Сохраняют свой регистр: "GitHub", "Telegram", "Neylin", "ELO", "Glicko-2".

---

## CSS

В кодовой базе не должно быть `text-transform: uppercase` или Tailwind `uppercase` на интерфейсных элементах. Если встречается — это баг, не фича.

Единственное допустимое исключение — если uppercase диктуется внешним стандартом (например, ISO-коды валют "USD", аббревиатуры "API").
